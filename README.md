# ELE3305-design-assignment
Designing a distributed system that is a component of an automobile dashboard . 
Ultrasonic parking sensors and fuel usage monitoring sensors are found in the majority of contemporary automobiles. Mainly three units :
•	a distance sensor unit, 
•	a fuel and speed sensor unit, and 
•	a display unit
each with a single microcontroller make up the system used in this exercise. Automotive environments typically employ the CAN bus. RS485 and MODBUS are the most common in automation. 
The controllers in this example are linked together using a straight forward RS232 serial interface.
